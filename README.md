# ReservaTalleres

Aplicación Android desarrollada en Java para la Práctica 3 de Desarrollo de Aplicaciones Android de UNIE Universidad.

## Descripción

La aplicación permite a los alumnos de una academia reservar plazas para diferentes talleres mediante tres pantallas:

1. **Datos personales:** introducción y validación de los datos del alumno.
2. **Reserva:** selección del taller, modalidad, servicios, plazas, fecha y hora.
3. **Resumen:** visualización de los datos y simulación del envío de la reserva.

## Tecnologías

- Java
- XML
- Android Studio
- SharedPreferences
